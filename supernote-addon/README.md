# Supernote Private Cloud - Home Assistant Add-on

Run [Supernote Private Cloud & Knowledge Hub](https://github.com/tomasbedrich/supernote)
as a Home Assistant add-on: a lightweight, self-hosted **Supernote Private
Cloud** sync server for your Ratta Supernote device, with optional AI
transcription, summarization, and semantic search powered by Google Gemini.

## Features

- Sync notebooks from your Supernote device using the official Private
  Cloud protocol.
- Browse notes, manage tasks, and export iCalendar (`.ics`) task feeds that
  Home Assistant's calendar integration can consume.
- Optional AI synthesis: handwriting transcription, daily/weekly/monthly
  summaries, and semantic search (requires a Google Gemini API key).
- Optional [Model Context Protocol](https://modelcontextprotocol.io/) server
  so AI agents (Claude, Gemini, ChatGPT, ...) can query your notes.

See the **Documentation** tab for setup instructions.
